# Hi, I’m Farook Fahath

I build Android apps and web tools for practical workflows, from private notification history to opportunity discovery and business administration.

## Skills demonstrated in these projects

- **Android:** Kotlin, Jetpack Compose, Room, WorkManager, and AndroidX Biometric.
- **Web interfaces:** React, TypeScript, Vite, HTML, CSS, and JavaScript.
- **Backend and data:** Python, FastAPI, Pydantic, SQLAlchemy, PostgreSQL, SQLite, and Alembic.
- **Application design:** structured validation, deterministic eligibility checks, CSV workflows, local persistence, and responsive interfaces.
